# Contributing

Open an issue describing the behavior or improvement before a large change. Keep contributions focused on this work portfolio and never add private information or unsupported professional claims.

1. Create a branch.
2. Install with `npm ci`.
3. Make the smallest coherent change.
4. Run `npm run validate`.
5. Check desktop and a narrow mobile viewport for UI changes.
6. Open a pull request explaining the purpose, changes, and checks.

Use real public data in the site. Tests may use clearly identified fixtures. Do not commit credentials, `.env` files, raw private account exports, or unrelated personal information. Keep accessibility and reduced-motion behavior intact. To update featured selections, verify the public repository and README first.
